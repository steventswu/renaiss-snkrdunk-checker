05 · Engineering notes

Patterns worth noticing

Stale-request protection uses two layers

The card effect aborts fetches during cleanup, while requestVersion.current prevents an older async chain from committing state even if cancellation arrives too late. Index fetching uses a lighter alive flag because its result is a single parallel batch.

State follows ownership

App owns data shared across sections. IndexCard owns transient hover state. SearchPanel and ApiSettings own form drafts. This minimizes prop surface while keeping the source of truth close to the behavior that changes it.

The browser is an external system

Effects connect React to Chrome storage, tab events, parent-frame messages, and HTTP. Each subscription effect returns cleanup; each network effect guards against updates after disposal.
